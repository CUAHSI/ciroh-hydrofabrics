# Consistency Check code

This directory holds the Consistency Check implementation, the Data Model
specifications under `models/`, and the recorded limits in `counts.yaml`.

The documentation lives in [`docs/consistency-checks/`](../../docs/consistency-checks/README.md).
Start with [Reading a report](../../docs/consistency-checks/reading-a-report.md),
or [Running and recording](../../docs/consistency-checks/running-and-recording.md)
for the command line and how to update `counts.yaml`.
