# CIROH Community HydroFabrics

The shared language of this project: research versions of the NextGen hydrofabric that CIROH researchers can build, change, and share alongside the official hydrofabric products.

Terms are spelled "Hydrofabric", matching NOAA OWP and USGS usage. "HydroFabric(s)" is reserved for the project's name and branding (CIROH Community HydroFabrics).

## Official and community

**Official Hydrofabric**:
Any hydrofabric published and maintained by its federal owner: the Reference Hydrofabric (USGS), the NOAA OWP Reference Hydrofabric, and the NOAA OWP NextGen Hydrofabric.
_Avoid_: operational hydrofabric, authoritative hydrofabric

**Community Hydrofabric**:
Any research-grade Modeling Hydrofabric generated by this project; the Community NextGen Hydrofabric is the first kind.
_Avoid_: CIROH Community Hydrofabric (the name of a separate UA product), research hydrofabric, custom hydrofabric

## Reference hydrofabrics

**Reference Hydrofabric**:
The national, model-agnostic flow network maintained by USGS (Blodgett et al., 2023) from which hydrofabrics are built.
_Avoid_: reference fabric, reference network, superCONUS

**NOAA OWP Reference Hydrofabric**:
NOAA OWP's corrected, versioned variant of the Reference Hydrofabric (e.g. v2.2, v2.3), distributed through Lynker Spatial.
_Avoid_: NOAA Reference Fabric, official reference, Lynker reference

## Modeling hydrofabrics

**Modeling Hydrofabric**:
A hydrofabric prepared for a specific modeling framework, built from the Reference Hydrofabric or one of its official variants.
_Avoid_: model hydrofabric, derived hydrofabric

**NOAA OWP NextGen Hydrofabric**:
NOAA OWP's official Modeling Hydrofabric for the NextGen framework (e.g. v2.2), built from the NOAA OWP Reference Hydrofabric.
_Avoid_: ngen hydrofabric, NextGen hydrofabric (unqualified), operational hydrofabric

**Community NextGen Hydrofabric**:
A research-grade Modeling Hydrofabric for the NextGen framework generated by this project, starting from either the Reference Hydrofabric or an official variant of the Reference Hydrofabric (e.g. NOAA OWP Reference Hydrofabric).
_Avoid_: research hydrofabric, custom hydrofabric

## Lifecycle

**Build**:
A Community Hydrofabric produced by one run of this project's pipeline, whether or not it has been reviewed.
_Avoid_: draft, working copy, run output

**Release**:
A reviewed, versioned Build published for others to use (e.g. Community NextGen Hydrofabric v0.1).
_Avoid_: system release, drop, snapshot

## Contributions

**Contribution**:
A proposed change to how a Community Hydrofabric is built, submitted for review on its way into a Release. Its kind is set by its purpose, not by how it is implemented.
_Avoid_: patch, PR, submission

**Correction**:
A Contribution that fixes errors in the network, geometry, or hydrolocations.
_Avoid_: fix, topo fix

**Enhancement**:
A Contribution that adds science content, such as attributes, model parameters, or states.
_Avoid_: value-added content, enrichment

**Method Change**:
A Contribution that changes how a processing step builds the hydrofabric.
_Avoid_: new stage, custom stage

## Between official and community

**Upstream Update**:
A change to an Official Hydrofabric that Community Hydrofabric Builds then take up.
_Avoid_: propagation, sync, pull-down

**Upstream Recommendation**:
A change shown in Community Hydrofabric work and offered to the owner of an Official Hydrofabric for possible adoption.
_Avoid_: propagation, backport, R2O handoff
